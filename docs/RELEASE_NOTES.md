# 天降风云录16-10 Android 1.6.1

- 文件：`TianJiangFengYun-1.6.1.apk`
- 架构：`arm64-v8a` / `armeabi-v7a`
- 最低系统：Android 6.0（API 23）
- SHA-256：以 Release 附件页面显示的 digest 为准。

安装前建议备份存档。旧测试包可直接覆盖安装。

## 本版更新

### 物理手柄

- 手柄接上即可用，不需要额外设置：**A 确认、B 取消、X 菜单、Y 使用**，
  左右肩键对应 Q/W 两个快捷键，十字键与**左摇杆**都能走（摇杆带 0.45 死区）。
- **支持真正的斜向行走**，松手立即停下；贴墙斜走会沿墙滑行，不会卡住。
- BACK 键交还系统（不再被游戏吞掉），返回键行为正常。
- 全部走引擎原生输入通路，没有加模拟层，延迟与键盘一致。

### 画面

- **修复窄地图左右走动时画面跳变**。原版有 85 张地图只有 20 格宽（640px），
  镜头边界被算成负数，画布整体偏移露出黑边，左右走动时来回跳。
  现在镜头在地图边界前就停住，读档进入也直接居中，不必先走两步才归位。

### 触屏

- 右下角两个按钮改为 **Xbox 布局**：A 在右下角，B 在其右上方，位置关系与手柄一致；
  按钮改成「字母大字 + 中文小字」两行，看得清也不挡画面。

## 已知限制

- 地图上「点哪走哪」需要寻路，本版未实现。
- 转盘抽奖等自定义排版界面尚未逐个适配点击命中。
- 物理手柄的震动（rumble）未接线。
