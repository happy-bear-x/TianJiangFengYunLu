# 天降风云录16-10 Android 1.6.2

本版起，每次发布提供**两个安装包**，按偏好选一个：

| 文件 | 说明 |
|---|---|
| `TianJiangFengYun-1.6.2.apk` | **原版**。游戏内容与原作者版本一致，只做安卓移植必需的适配与 bug 修复。 |
| `TianJiangFengYun-1.6.2-optimized.apk` | **优化版**。原版全部内容 + 体验增强（本版是自动存档）。 |

- 架构：`arm64-v8a` / `armeabi-v7a`
- 最低系统：Android 6.0（API 23）
- SHA-256：以 Release 附件页面显示的 digest 为准。

两版包名相同，只能装一个；**覆盖安装会保留存档**，换版本不会丢档。
安装前仍建议备份存档。

## 本版更新（两个版本都有）

### 触屏：摇杆跟手范围扩大

- 触发区从「左下角 30% × 32%」放宽到 **42% × 48%**，拇指不用再往屏幕最下角去够；
  摇杆轮盘本身的大小没有变。
- 待机提示圈从屏幕高度 86% 上移到 **78%**，位置更接近拇指自然落点。
- 仍保留明确的矩形触发范围，而不是整片左下半屏——早期用过更大范围，
  结果左侧菜单项的点击会被摇杆吃掉。

### 修复：传送后留下的主角残影

- 队伍跟随在地图传送后把**所有跟随者 moveto 到主角同一格**，三个身影精确叠在一起，
  跟随精灵又压在主角之下，站住就是一团重影。现在按朝向排到身后 1/2/3 格。
- 可见敌人触发战斗后精灵没被回收，战斗结束回到地图会留一只不动的怪物。
  现在触发战斗即回收，管理器销毁时也逐个释放。

## 优化版独有

### 自动存档（5 份轮换）

- 读档界面保留原来的 4 个手动槽，**最下面新增一行「自动存档」**，
  点进去是 5 份自动档，显示游戏时长与保存时间，可任选一份载入。
- **挂机不会覆盖存档**：只有换地图、或角色真的挪过位置，才会落盘。
  实测原地挂机两分钟，一份都不会写。
- 落盘只在**安全点**进行：事件解释器空闲、没有对话框 / 战斗 / 商店 / 场景切换、
  主角不在移动中。避免把「半个剧情」写进存档导致读回来卡关。
- 节流：换图落地后补一份；同一张地图满 90 秒且有进展再补；任何情况 20 秒内不重复写。
  5 份按时间覆盖最老的一份，始终保有历史。
- 写盘先写临时文件再改名，写到一半被系统杀掉也不会产生「半截存档」；
  损坏的自动档在读档界面显示为空槽，不会让界面崩溃。

## 1.6.1 已包含

- 物理手柄原生支持：A 确认 / B 取消 / X 菜单 / Y 使用，十字键与左摇杆都能走，
  支持真斜走与贴墙滑行。
- 修复 85 张窄地图（20 格宽）左右走动时画面跳变，镜头在地图边界前停住。
- 右下角按钮改 Xbox 布局（A 在下、B 在右上）。

## 已知限制

- 地图上「点哪走哪」需要寻路，本版未实现。
- 转盘抽奖等自定义排版界面尚未逐个适配点击命中。
- 物理手柄的震动（rumble）未接线。
