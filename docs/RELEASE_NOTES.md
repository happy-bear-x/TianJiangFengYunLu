# 天降风云录16-10 Android 1.6.0

- 文件：`TianJiangFengYun-1.6.0.apk`
- 架构：`arm64-v8a` / `armeabi-v7a`
- 最低系统：Android 6.0（API 23）
- SHA-256：以 Release 附件页面显示的 digest 为准。

安装前建议备份存档。旧测试包可直接覆盖安装。

## 本版更新

### 画面

- 画布由 4:3（640×480）扩展为 16:9（853×480），1280×720 / 1920×1080
  屏幕等比放大 1.5× / 2.25×，不留黑边、不拉伸变形、不重复图块。
- 地图横向可视范围从 20 格提升到 26.7 格，瓦片渲染同步扩展。
- 镜头在地图边界前停止移动，初始位置也会钳制，不会出现越界空白。
- 标题菜单居中；开场 / 结局动画的 161px 黑边修正。
- 属性、物品、技能、商店、穿戴等组合界面的文字重新对齐到背景槽位。

### 操作

- 左下角浮动摇杆：落指即生成，摇杆帽跟手，支持 8 方向（含真正的斜向
  行走）。贴墙斜走时自动沿墙滑动，不会因为一点偏移就卡住不动。
- 界面上可直接点选：点菜单项即选中并确认；对话框点击推进。
- 菜单类界面点窗口外面 = 返回。
- 地图左上角隐藏热区可呼出菜单（与屏幕上的「返回」等价）。
- 保留右下角「选中 / 返回」按钮与物理手柄、键盘通路。

已知限制：地图上「点哪走哪」需要寻路，本版未实现；转盘抽奖等自定义
排版界面尚未逐个适配点击命中。
